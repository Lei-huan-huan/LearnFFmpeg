## 这个 app 是干嘛用的？

简单来说，它就是一个能**播放各种视频**的小工具，类似于你手机里自带的"视频播放器"，但它更厉害一点：

- 不只能看**手机里保存的视频**
- 还能**直接粘贴一个视频网址**就播放（不用先下载）
- 甚至可以**看直播**（比如游戏直播、监控画面这种实时画面）

打开 app，你会看到一个输入框、几个按钮，下面是播放画面，操作非常简单。

---

## 怎么用？三步搞定

### 第 1 步：告诉它你想看什么

你有两种方式：

**方式 A：看手机里的视频**
- 点一下 **「选择文件」** 按钮
- 从相册里挑一个视频
- 选好后，输入框会自动填上视频的位置

**方式 B：看网上的视频或直播**
- 把视频链接（一串以 `http` 或 `rtmp` 开头的网址）直接复制粘贴到输入框里就行

### 第 2 步：点「播放」

点一下 **「播放」** 按钮，下面的黑色区域就会开始放视频啦。

播放时，app 还会告诉你：
- 视频的**清晰度**（比如 1920×1080）
- 视频的**总时长**
- 当前状态（准备中 / 正在播放 / 播完了 / 出错了 等）

### 第 3 步：想停就停

点 **「停止」** 按钮，视频立刻停下来。

> 小贴士：如果你把 app 切到后台（比如去回个微信），视频会自动暂停；切回来再点播放就行。

## 它能播什么？

| 来源 | 例子 |
| --- | --- |
| 手机相册里的视频 | 自己拍的、下载的视频文件 |
| 网上的视频链接 | 类似 `https://xxx.com/movie.mp4` 这种 |
| 直播链接 | 类似 `rtmp://xxx/live/xxx` 这种实时画面 |

常见的视频格式它都能播，遇到播不了的也不用紧张，换一个试试就好。

## 常见问题

**Q：为什么点了播放没反应？**
- 检查一下输入框里的地址对不对，链接是不是已经失效了
- 如果是网络视频，确认手机有没有连网

**Q：画面卡顿怎么办？**
- 大概率是网速不够，换个 WiFi 或者等一会儿
- 也可能是视频本身太大、太清晰

**Q：「RTMP」是什么？**
- 你可以理解成一种"直播专用的网址"。一般的视频网址是 `http` 开头，直播网址常常是 `rtmp` 开头。普通用户用不到的话，忽略就行。
